# 素材来源

鲸鱼原图：用户提供的 `D:\桌面\白背景下的座头鲸特写.png`。

工具：内置 imagegen，单次透明去背编辑。随后使用 `scripts/prepare-whale.py` 验证透明通道、无损整理 PNG 并缩放生成图标；未使用白色阈值去背。

完整提示词：

> Use case: background-extraction. Edit target: the provided realistic humpback whale image. Create a clean transparent RGBA cutout for an actual Windows desktop pet. Remove ONLY the white background. Preserve the entire whale, its original pose, left tail, foreground long flipper, white belly, lower flipper, dark blue skin texture, head details, proportions, and realistic identity. The belly and white skin MUST remain fully opaque. Keep entire whale in frame with small transparent margins, no clipping, no shadow, no new water, no new objects, no text, no artistic restyling. Background must be genuinely transparent, not a checkerboard. Save the final image to a local file and return its path if supported.

水波贴图：由源码 `helper/shared/sprites.js` 生成，不额外调用生图工具。音效为本项目离线合成，台词为本地原创文案。用户可在数据目录中添加同名 PNG/WAV 覆盖，缺少可选素材时使用程序化版本。
